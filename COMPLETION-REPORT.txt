VARIABLE REFERENCE
================================================================================

Core Variables (All Templates):
  • skillName: Display name (e.g., "WordPress Database Migration")
  • skillSlug: Kebab-case ID (e.g., "wp-db-migrate")
  • skillDescription: Feature description
  • authorName: Author/creator name

Configuration Values:
  • version: Semantic version (1.0.0)
  • nodeVersion: Minimum Node.js version
  • testCoverageThreshold: Jest coverage % (default: 80)
  • license: License type (default: "MIT")
  • projectType: Category (e.g., "Claude skill + plugin")
  • language: Primary language (e.g., "Bash + JavaScript")
  • branchPattern: Git branch regex pattern

Boolean Conditionals:
  • hasSkillDirectory: Has skill/ directory
  • hasPluginDirectory: Has plugin/ directory
  • hasShellScripts: Has shell scripts
  • hasBatsTests: Has BATS integration tests
  • hasYamlLinting: Has YAML linting support
  • hasProductionDeps: Has production dependencies
  • hasAnthropicSdk: Needs @anthropic-ai/sdk
  • hasMigrationApi: Has migration API
  • skipTests: Skip tests in pre-commit
  • useEsModules: Use ES modules in Jest
  • hasSetupScript: Has setup script
  • hasDocs: Has documentation folder

String Overrides:
  • quickStartCommand: Custom initial command
  • problemStatement: Custom problem description
  • skillDocPath: Path to skill documentation
  • licenseText: Full license text

Array Variables:
  • features[]: {title, description} objects
  • problemFeatures[]: Problem solution bullets
  • usageExamples[]: {title, example, description}
  • customRequirements[]: Additional requirement strings
  • acknowledgments[]: Credit strings
  • dependencies[]: {name, version} for prod deps

USAGE QUICK START
================================================================================

1. Copy templates to your project:
   cp /tmp/skill-scaffold-phase1/templates/*.mustache your-project/

2. Install Mustache renderer:
   npm install mustache

3. Create configuration file (config.json):
   {
     "skillSlug": "my-skill",
     "skillName": "My Awesome Skill",
     "skillDescription": "What it does",
     "version": "1.0.0",
     "authorName": "Your Name",
     "nodeVersion": "24",
     "license": "MIT",
     "testCoverageThreshold": 80,
     "hasShellScripts": false,
     "hasBatsTests": false,
     "hasYamlLinting": false,
     "branchPattern": "^(feature|fix|docs)/"
   }

4. Render templates using Mustache:
   node render.js config.json

5. Customize output files as needed
